## ماذا يقدم التطبيق؟

يستخدم Redro Islamic موقعك لحساب مواقيت الصلاة المحلية، ويعرض الصلاة القادمة والعد التنازلي. ويمكنك تفعيل إشعارات الأذان لكل صلاة على حدة، اختيار مؤذن ومعاينة صوته، وجدولة التنبيهات للأيام السبعة القادمة حتى عند إغلاق التطبيق.

ويضم التطبيق كذلك المصحف، الأذكار، السبحة الإلكترونية، اتجاه القبلة، حاسبة الزكاة، رمضان، والتقدم اليومي. تُحفظ الإعدادات والموقع والتقدم محليًا على الجهاز، بينما تُستخدم [AlAdhan API](https://aladhan.com/prayer-times-api) لمواقيت الصلاة.

## الميزات الرئيسية

- GPS مع طلب صلاحية Android والاعتماد على الموقع الدقيق عند توفره.
- إشعارات محلية للأذان وصوت أذان مضمّن داخل APK.
- إعدادات مستقلة لكل صلاة، وخيار الاهتزاز والأصوات.
- تصميم عربي RTL يعمل كتطبيق Web/PWA وAndroid.
- شعار محلي للموقع وPWA ونسخة Android، بلا اعتماد على أيقونات خارجية.
- تحويل JavaScript وPolyfills لدعم WebView القديم، مع شاشة خطأ وإعادة محاولة بدل التعليق على التحميل.

### التوافق مع الأجهزة القديمة

تمت معالجة مشكلة أجهزة Samsung وAndroid القديمة التي كانت تتوقف عند «جاري التحميل» بسبب عدم دعم بعض صيغ JavaScript الحديثة. نسخة البناء الجديدة تحول التطبيق إلى صيغة متوافقة مع WebView قديم وتضم Polyfills للدوال الشائعة. يفضّل تحديث **Android System WebView** وChrome إن كان ذلك ممكنًا، لكن التطبيق يتضمن الآن وضع توافق احتياطيًا.

## تنزيل APK من GitHub Actions

يُبنى APK تلقائيًا عند كل تحديث لفرع `main` عبر [Build Android APK](../../actions/workflows/android-apk.yml). عند وجود أسرار التوقيع الأربعة يُرفع `redro-islamic-release-apk`، وإلا يرفع Workflow نسخة اختبار باسم `redro-islamic-debug-apk` حتى لا يتوقف البناء.

لتفعيل Release الموقّع مرة واحدة، أنشئ مفتاحًا خاصًا ثم أضف الأسرار التالية من **Settings → Secrets and variables → Actions**: `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS`، `ANDROID_KEY_PASSWORD`. لا تضع ملف keystore أو كلمات المرور داخل Git.

نسخة Release الموقعة أفضل من نسخة Debug للتثبيت والتحديث. قد يستمر Android/Play Protect أحيانًا في عرض تحذير عند تثبيت أي APK من خارج Google Play؛ النشر عبر Google Play (اختبار داخلي أو إنتاج) هو الطريقة النهائية لإزالة تحذيرات المصدر غير المعروف.

## تشغيل وبناء محلي

```bash
npm ci
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

يظهر APK التجريبي في `android/app/build/outputs/apk/debug/`. يحتاج Android 13 إلى السماح بالإشعارات، وتحتاج التنبيهات الدقيقة في Android 12+ إلى السماح بالمنبهات الدقيقة من إعدادات النظام.

## ملاحظات Redmi / Xiaomi

اسمح للموقع أثناء استخدام التطبيق، فعّل الموقع الدقيق، واجعل البطارية **بلا قيود** وفعّل التشغيل التلقائي حتى تستمر إشعارات الأذان في الخلفية.

## الخصوصية والأمان

لا يطلب التطبيق حسابًا ولا يرسل إعداداتك أو تقدمك إلى خادم. الموقع يُستخدم لحساب المواقيت ويُحفظ محليًا. مفاتيح توقيع Android محفوظة في GitHub Secrets ولا توجد داخل المستودع.
