# Redro Islamic

تطبيق إسلامي شامل مبني بـ HTML + CSS + JavaScript النقي (بدون أي تسجيل دخول أو Backend).

## المميزات

- **مواقيت الصلاة** دقيقة حسب موقعك (API Aladhan)
- **المصحف الشريف** كامل مع 114 سورة (API AlQuran Cloud)
- **الأذكار** (صباح، مساء، نوم، بعد الصلاة...)
- **السبحة الإلكترونية** مع عدة أذكار وأحاديث
- **اتجاه القبلة** مع بوصلة حية
- **حاسبة الزكاة** (مال، ذهب، فضة)
- **عمل اليوم والليلة** قائمة مهام يومية مع حفظ محلي
- واجهة عربية كاملة RTL وتصميم عصري

## طريقة التشغيل

1. افتح ملف `index.html` في أي متصفح حديث (Chrome / Firefox / Safari / Edge)
2. أو ارفعه على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel...)

لا يحتاج سيرفر أو قاعدة بيانات. كل شيء يعمل من المتصفح + APIs عامة.
